# 📡 Volume Radar

**거래대금 상위 + 상승 + 실적** 종목 레이더. ai2 컨센서스 데이터를 소비하는 크롤링-프리 파생 프로그램.

## 컨셉

> "돈이 몰리는 곳(거래대금 상위)에서, 오르고 있고(전일 대비 상승), 실적이 받쳐주는(흑자 + 성장률 20%↑) 종목만 남긴다. 그리고 **10거래일 누적으로 반복 등장하는 종목**을 찾는다."

단발성 거래량 급증은 뉴스 노이즈가 많지만, 반복 등장 = 지속적 자금 유입 + 펀더멘털.

## 데이터 흐름

```
ai2 레포 (매일 새벽 자동 크롤, 전일 종가/거래량/컨센서스)
   ↓ raw CSV fetch (크롤링 없음)
daily_update.py (05:30 KST, GitHub Actions)
   ├─ 스냅샷 저장 → 전일 대비 등락률 자체 계산
   ├─ 거래대금 상위 100 중 [상승 + 실적] → data/lists/{거래일}.json
   └─ 최근 10거래일 누적 랭킹 → data/accumulation.json
   ↓
app.py (Streamlit) — 일별 리스트 / 누적 랭킹 / 등장 매트릭스
```

## 리스트 기준

| 항목 | 기준 |
|---|---|
| 순위 | **거래대금**(종가×거래량) — 거래량(주수)은 저가주 왜곡이 있어 미사용 |
| 상승 | 전 거래일 종가 대비 등락률 > 0 (자체 스냅샷 비교) |
| 실적 | 영업이익 흑자(25E or 26E) + 매출/영업이익 최대성장률 ≥ 20% |
| 휴장 처리 | 주말 스킵 + 거래량 총합 동일 시(공휴일) 스킵 |

## 누적 랭킹

- 최근 **10거래일** 리스트 대상, **등장 횟수 ↓ → 평균 순위 ↑** 정렬
- 연속 등장 스트릭, 최고 순위, 신규 진입(🆕) 표시
- 등장 매트릭스(종목 × 거래일 ●)로 "이벤트성 vs 지속 유입" 시각 판별

## 파일

- `radar_core.py` — 스냅샷/리스트/누적 로직
- `daily_update.py` — 매일 실행 엔트리 (GitHub Actions)
- `backfill.py` — 일회성: ai2 git 히스토리에서 과거 15일 소급 생성
- `app.py` — Streamlit 대시보드 (비밀번호 게이트)
